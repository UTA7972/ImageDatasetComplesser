# 画像データセット圧縮・解凍・パッケージングツール (Image Dataset Compressor & Decompressor)

指定したフォルダ配下の画像データセット（20枚以上の画像が存在するフォルダ）を自動検出し、解像度の異なる画像を最大サイズへ**黒補完（パディング）**したうえで、高速な**並列処理**で `dataset.npz` にパッケージング圧縮する、およびそれを**元の完全な解像度・ファイル名へ復元（解凍）**する統合デスクトップアプリケーションです。

---

## 🌟 主な機能・特徴

### 1. 📦 画像データセット圧縮 (Pack)
- **自動データセット判定 & 再帰検索**:
  - フォルダ内に画像ファイルが **20枚以上** ある場合にデータセットと自動判定します。
  - サブフォルダ内のデータセットも階層をたどって自動探索・処理します。
- **マルチコア並列処理**:
  - PCのCPUコア数を自動検出し、任意のコア数を選択して読み込み・リサイズパディングを高速並列処理します。
- **画像サイズの自動統一（黒補完）**:
  - データセット内で画像サイズが異なる場合、一番大きい画像サイズ（`max_width` × `max_height`）を自動計測。
  - 足りない右側・下側の領域を黒（`0`）で補完して揃えます。
- **`dataset.npz` 圧縮 & メタデータ保存**:
  - 画像データを `dataset.npz` (Numpy Array `[N, height, width, channels]`) として各データセットフォルダに書き出します。
  - 元のファイル名および元の画像サイズを記録した `images_index.csv` を同じフォルダに生成します。
  - 正常に圧縮保存が完了した後、元の画像ファイルのみを安全に削除します。

---

### 2. 🔓 圧縮データセット解凍・復元 (Unpack)
- **黒補完の自動除去 & 完全復元**:
  - `images_index.csv` に記録された解像度情報を参照し、パディングされた黒領域を正確に切り落として（クロップ）、元の画像サイズに完全復元します。
- **正確なファイル名復元**:
  - インデックス順序に基づいて、元の画像ファイル名と形式で画像を復元します。
- **マルチコア並列解凍**:
  - 解凍・画像復元時もCPUマルチコアを用いて高速に並列処理します。
- **自動クリーンアップ**:
  - 解凍・復元が成功した後、`dataset.npz` および `images_index.csv` を安全に削除します。

---

## 🚀 起動方法

仮想環境 `env` を有効化し、`main.py` を実行します。

### PowerShell の場合
```powershell
.\env\Scripts\Activate.ps1
python main.py
```

### または直接実行
```powershell
.\env\Scripts\python.exe main.py
```

## 📁 フォルダ構成例

### 圧縮後
```text
dataset_folder/
├── dataset.npz          # 圧縮された全画像データのNumpy配列 (npz)
└── images_index.csv     # 画像ファイル名・インデックス・元の解像度メタデータ
```

### 解凍・復元後
```text
dataset_folder/
├── image01.jpg          # 元の解像度に復元された画像
├── image02.png
...
```
