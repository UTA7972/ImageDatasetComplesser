# 画像データセット圧縮・パッケージングツール (Image Dataset Compressor)

指定したフォルダ配下の画像データセット（20枚以上の画像が存在するフォルダ）を自動検出し、解像度の異なる画像を最大サイズへ**黒補完（パディング）**したうえで、高速な**並列処理**で `dataset.npz` にパッケージング圧縮するデスクトップアプリケーションです。

---

## 🌟 主な機能・特徴

1. **直感的なGUIインタフェース**:
   - 処理対象フォルダをGUI上で簡単に指定できます。
   - スキャン機能により事前にデータセットフォルダの一覧を確認できます。
   - リアルタイムな進捗ログとプログレスバーを表示します。

2. **自動データセット判定 & 再帰検索**:
   - フォルダ内に画像ファイルが **20枚以上** ある場合にデータセットと自動判定します。
   - サブフォルダ内のデータセットも階層をたどって自動探索・処理します。

3. **マルチコア並列処理**:
   - PCのCPUコア数を自動検出し、任意のコア数を選択して読み込み・リサイズパディングを高速並列処理します。

4. **画像サイズの標準化（黒補完）**:
   - データセット内で画像サイズが異なる場合、一番大きい画像サイズ（`max_width` × `max_height`）を自動計測。
   - 足りない右側・下側の領域を黒（`0`）で補完して揃えます。

5. **npz圧縮 & メタデータインデックス保存**:
   - 画像データを `dataset.npz` (Numpy Array `[N, height, width, channels]`) として各データセットフォルダに書き出します。
   - 元のファイル名および元の画像サイズを記録した `images_index.csv` を同じフォルダに生成します。
   - 正常に圧縮保存が完了した後、元の画像ファイルのみを安全に削除します。

---

## 🚀 起動方法

仮想環境 `env` を有効化し、`main.py` を実行します。

### PowerShell の場合
```powershell
.\env\Scripts\Activate.ps1
python main.py
```

### または直接実行
```powershell
.\env\Scripts\python.exe main.py
```

---

## 📁 出力ファイル構成例

処理後のデータセットフォルダ構造:
```text
dataset_folder/
├── dataset.npz          # 圧縮された全画像データのNumpy配列 (npz)
└── images_index.csv     # 画像ファイル名・インデックス・元の解像度メタデータ
```

`images_index.csv` の内容例:
```csv
index,filename,original_width,original_height
0,sample_01.jpg,1920,1080
1,sample_02.png,1280,720
...
```
